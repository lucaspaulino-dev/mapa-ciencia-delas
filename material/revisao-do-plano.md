# Antes de aprovar o plano da Arquiteta

Revisar o plano encontra mais problemas do que revisar o código, e consertar um plano custa uma frase; consertar o código custa reescrever. Você é a revisora do plano. Responda às quatro perguntas antes de dizer "sim".

1. **Existe?** Todo arquivo, tipo, store e comando citado existe no projeto ou é criado por uma tarefa anterior do próprio plano? Confira no explorador de arquivos.
2. **Cobre?** Toda linha de aceite tem uma tarefa que a entrega? Toda tarefa serve a alguma linha de aceite? Tarefa sem aceite é escopo entrando de carona.
3. **Roda na ordem?** Alguma tarefa depende de algo que só uma tarefa depois dela cria?
4. **É pequeno?** Cada tarefa toca no máximo 2 arquivos de código e termina com um comando que prova que funcionou?

Se alguma resposta for "não", peça a correção à Arquiteta antes de aprovar. Edite o plano à mão sem medo: ele é seu.
